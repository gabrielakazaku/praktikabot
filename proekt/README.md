# Praktikabot

## Описание проекта
Этот проект создан для практики работы с Git, GitHub и Python.

## Структура проекта
- app/ - основной код проекта
- examples/ - примеры и скриншоты работы
- requirements.txt - зависимости Python

## Установка
```bash
# Клонирование репозитория
git clone https://github.com/gabrielakazaku/praktikabot.git
cd praktikabot
```

## Запуск
```bash
python app/main.py
```
